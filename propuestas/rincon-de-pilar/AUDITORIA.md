**Frases agregadas.** Varias frases le atribuyen al sistema algo que el original no dice:
- **Pág. 15:** "acompaña la consulta hasta que la toma recepción". El original no dice que los datos acompañen la conversación derivada.
- **Pág. 16:** "Recibe la conversación con los datos del cliente" y "Recepción las retoma desde el panel". El original no describe cómo usa recepción el panel ni qué datos recibe.

- **Pág. 18:** "Encuentra el salón cuando lo busca" (promete un resultado), "sin esperas" (exagera "optimizada para que cargue rápido") y "con sus datos ya reunidos" (no está descrito).

**Cómo corregirlas:** reescribir cada frase con lo que dice el original, sin cambiar el diseño:
- recepción recibe la conversación derivada cuando el cliente está realmente interesado o pide presupuesto;
- el panel organiza las consultas del formulario;
- la base de datos se aclara como propia de la Opción B;
- las medidas de seguridad quedan como "a definir con Rincón de Pilar".
